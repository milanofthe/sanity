# sanity

A structural overview of a repository: every file as a panel on one canvas,
laid out by size and folder, live while you work and back through its git
history.

```sh
npm install -g @milanofthe/sanity
sanity            # the folder you are in
sanity ../other   # or another one
```

Or without installing: `npx @milanofthe/sanity`.

macOS (Intel and Apple Silicon) and Windows x64. The package brings the same
app the installers do, in the platform package npm picks for your machine.
The website runs anywhere: https://sanity.milanrother.com

Source, releases and documentation: https://github.com/milanofthe/sanity
